Weather Widget

Current conditions, alerts, hourly and 7-day forecast from the National Weather Service. Free, no API key, U.S. locations only. Add one script and one <div>.

Full width (dark)

Wide layouts show the forecast text for each day. Active NWS alerts appear as expandable banners.

<div data-sg-weather
     data-lat="41.5868"
     data-lon="-93.6250"
     data-theme="dark"></div>

<script src="https://cgermain45.github.io/cashbid-widget/sg-weather.js"></script>

The script loads sg-weather.css from the same folder automatically, so it works in a CMS that strips <link> tags. You can also add the stylesheet yourself.

Light and sidebar sizes

The layout adapts to the width of its container, not the screen. The green card uses data-theme="none" to pick up the site's colors.

<div data-sg-weather
     data-lat="37.6872" data-lon="-97.3301"
     data-name="Wichita, KS"
     data-days="5"></div>

<div data-sg-weather
     data-lat="40.8136" data-lon="-96.7026"
     data-theme="none"
     data-hours="6"
     data-days="3"></div>

<style>
  .sidebar [data-sg-weather] {
    --sgw-sun: #fde68a;     /* icon colors, borders, etc. are all variables */
    --sgw-cloud: #bbf7d0;
  }
</style>

Options

AttributeDefaultWhat it does
data-lat, data-lonrequiredLocation in decimal degrees (right-click a spot in Google Maps to copy them). U.S. only.
data-nameNWS city, stateLocation label shown at the top
data-unitsusus (°F, mph, inHg) or si (°C, km/h, hPa)
data-themelightlight, dark, or none (inherit your site's colors)
data-days7Days in the forecast list (1–7)
data-hours12Hours in the hourly strip (0 hides it)
data-alertstrueShow active NWS watches, warnings and advisories
data-refresh15Minutes between refreshes (0 turns it off)

Data: api.weather.gov. NWS data is U.S. government public domain and free for commercial use. The location lookup is cached in the browser for a week, so each refresh makes 3–4 small requests.
