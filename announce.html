Announcements Widget

Rotating slides for messages and ads: a headline, message, optional image and background color. Load slides from a hosted JSON file so every screen shares them, or write them inline.

From a hosted file

Edit the JSON file and every page or screen using it updates within a few minutes. This example uses examples/announcements.json from this repo.

<div data-sg-announce
     data-feed="https://yourcompany.com/announcements.json"></div>

<script src="https://cgermain45.github.io/cashbid-widget/sg-announce.js"></script>

Inline slides, sidebar size

Slides can also live right in the page. The layout adapts to the box it's in.

<div data-sg-announce data-interval="6">
  <script type="application/json">
    { "slides": [
      { "title": "Board closed Monday", "text": "Markets closed for the holiday." },
      { "title": "Text alerts", "text": "Sign up at the scale house.", "background": "#1e3a8a" }
    ] }
  </script>
</div>

File format

{
  "interval": 8,                       // seconds per slide (optional)
  "slides": [
    {
      "title": "Harvest hours",          // headline (optional)
      "text": "Open 6am – 10pm",         // message; line breaks are kept (optional)
      "image": "https://…/ad.jpg",       // image URL (optional)
      "imageMode": "side",               // "side" = beside the text, "fill" = fill the panel
      "background": "#14532d"            // background color (optional)
    }
  ]
}
AttributeDefaultWhat it does
data-feednoneURL of a JSON file in the format above. If it's on another site, that host must allow cross-site access (GitHub Pages does).
data-interval10Seconds per slide (the file's interval wins if set)
data-refresh5Minutes between re-reading data-feed
data-themelightlight, dark, or none (inherit your site's colors)
--sga-height300pxCSS variable for the widget's height

An image with no text in "fill" mode is shown whole (never cropped), which suits ad graphics. Slides pause while the mouse is over them, and the dots let viewers pick a slide. In the quoteboard, use ✏️ on an Announcements panel to write slides or point it at a file.
