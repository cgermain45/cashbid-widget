Futures Quotes

Futures quotes from Barchart OnDemand, as a table or a scrolling ticker. Viewers enter a Barchart OnDemand API key inside the widget.

By default the API key is never part of the embed code. It stays in the viewer's browser for the session, or until they choose "Forget API key" if "Remember on this device" is checked. One key covers every futures table and ticker on the page. Site owners can build a key in with data-apikey, but anyone can then read it in the page source.

Ticker

Month, last price and change for each contract.

<div data-sg-futures-ticker
     data-symbols="ZCZ26,ZCH27,ZSX26,ZSF27,ZWZ26,ZWH27"></div>

<script src="https://cgermain45.github.io/cashbid-widget/sg-futures.js"></script>

Table

Name, symbol, month, last and change by default. Use the ⚙ menu to show open, high, low, close, % change or volume, or to switch to fractional prices (497'2).

<div data-sg-futures
     data-symbols="ZCZ26,ZCH27,ZSX26,ZSF27,ZWZ26,ZWH27"
     data-columns="name,symbol,month,last,change"></div>

<script src="https://cgermain45.github.io/cashbid-widget/sg-futures.js"></script>

The script loads its stylesheets from the same folder automatically.

Options

AttributeDefaultWhat it does
data-symbolsrequiredComma-separated contracts. The month comes from the symbol: ZCZ26 = Dec 26.
data-columnsname,symbol,month,last,changeTable only. Also available: pctchange, open, high, low, close, volume.
data-formatdecimaldecimal (497.25) or fraction (497'2, grain eighths)
data-themetable light, ticker darklight, dark, or none (inherit your site's colors)
data-refresh30Seconds between refreshes (0 turns it off)
data-editablefalseTable only. true adds an "Add symbol" box and a × on each row so viewers can change the list. Changes last until the page reloads; listen for the sg:symbols event to save them. (Quoteboard panels are always editable and save automatically.)
data-apikeynoneBuilds an OnDemand API key into the widget so viewers aren't asked for one. Visible to anyone in the page source — only use a key you're comfortable publishing.
data-feedOnDemand getQuote.jsonAlternate quote URL with the same response format, e.g. your own proxy
data-labelFuturesTicker only. Badge text, or "" to hide it.
data-speed50Ticker only. Scroll speed in pixels per second.
data-show-nametrueTicker only. Show the commodity name before the month (e.g. "Corn Dec 26").

Change and % Chg come from OnDemand's netChange and percentChange. Close is today's close once it's posted, otherwise the previous close. Last prices flash green or red when they move between refreshes.
