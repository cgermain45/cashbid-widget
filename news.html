News Ticker

Scrolling Barchart news headlines from Barchart OnDemand (getNews.json). Viewers enter a Barchart OnDemand API key inside the widget.

It uses the same API key as the futures widgets: a key entered in either one works in both. By default the key is never part of the embed code; it stays in the viewer's browser for the session, or on the device if "Remember on this device" is checked. Site owners can build a key in with data-apikey, but anyone can then read it in the page source.

Ticker

Newest headlines first. Hover to pause; click a headline to open the story.

<div data-sg-news-ticker data-sources="BRUG"></div>
<script src="https://cgermain45.github.io/cashbid-widget/sg-news.js"></script>

The script loads its stylesheets from the same folder automatically.

Options

AttributeDefaultWhat it does
data-sourcesBRUGNews source code(s). Only BRUG is set up for now.
data-max20Most headlines to scroll
data-refresh5Minutes between refreshes (0 turns it off)
data-linkstrueHeadlines open the story on barchart.com in a new tab. false for plain text.
data-labelNewsBadge text, or "" to hide it
data-themedarklight, dark, or none (inherit your site's colors)
data-speed50Scroll speed in pixels per second
data-apikeynoneBuilds an OnDemand API key into the widget so viewers aren't asked for one. Visible to anyone in the page source.
data-feedOnDemand getNews.jsonAlternate news URL with the same response format, e.g. your own proxy
