Cash Bid Ticker

A scrolling cash bid ticker for any web page. Add one stylesheet, one script and one <div>.

Default (dark)

One item per location and commodity, using the nearest delivery month.

<link rel="stylesheet" href="https://cgermain45.github.io/cashbid-widget/sg-ticker.css">

<div data-sg-ticker
     data-json="https://stonegrain.agricharts.com/inc/cashbids/cashbids-json.php"></div>

<script src="https://cgermain45.github.io/cashbid-widget/sg-ticker.js"></script>

Light, filtered, linked

Only corn and soybeans, slower, and each item links to your cash bids page.

<div data-sg-ticker
     data-json="https://stonegrain.agricharts.com/inc/cashbids/cashbids-json.php"
     data-theme="light"
     data-commodities="Corn,Soybeans"
     data-speed="35"
     data-link="/cash-bids"></div>

Blends into your site

data-theme="none" uses your page's colors. Fine-tune with CSS variables.

<div data-sg-ticker
     data-json="https://stonegrain.agricharts.com/inc/cashbids/cashbids-json.php"
     data-theme="none"
     data-label="Today's Bids"
     data-show-location="false"></div>

<style>
  .site-header [data-sg-ticker] {
    --sgt-accent: #fde68a;   /* price color */
    --sgt-up: #86efac;
    --sgt-down: #fca5a5;
  }
</style>

Options

AttributeDefaultWhat it does
data-jsonStone Grain feedCash bid feed URL
data-labelCash BidsBadge on the left. Set to "" to hide it.
data-themedarkdark, light, or none (inherit your site's colors)
data-speed50Scroll speed in pixels per second
data-refresh5Minutes between refreshes. 0 turns it off.
data-shownearestnearest = one per location and commodity, all = every delivery period
data-locationsallComma-separated location names to include
data-commoditiesallComma-separated commodity names to include
data-show-locationtrueShow the location name on each item
data-show-deliverytrueShow the delivery month (e.g. "Corn Nov")
data-show-changetrueShow the ▲/▼ change
data-linknoneMakes each item a link to this URL

Cash prices follow each bid's rounding value, like the main widget. Prices that change on a refresh flash green or red. The ticker pauses on hover and has a pause button. Visitors who prefer reduced motion get a swipeable strip instead of auto-scroll.
