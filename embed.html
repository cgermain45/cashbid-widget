Video & Web Embed

Show a live camera (like a truck scale), a video or HLS stream, a web page, or custom HTML. Paste an address and the widget works out how to display it.

Camera or stream

Most IP cameras have a "live view" address. Paste it as data-url. This example uses a still image from this site, refreshed every few seconds, the same way a camera snapshot address works.

<!-- IP camera live view (MJPEG) -->
<div data-sg-embed data-url="https://camera.example.com/mjpg/video.mjpg"></div>

<!-- HLS live stream -->
<div data-sg-embed data-url="https://stream.example.com/scale/index.m3u8"></div>

<!-- Custom HTML, e.g. a vendor's embed code -->
<div data-sg-embed>
  <template> …your HTML… </template>
</div>

<script src="https://cgermain45.github.io/cashbid-widget/sg-embed.js"></script>

What the URL is detected as

Address looks likeShown as
…/video.mjpg, …mjpeg…, video.cgi, axis-cgi/mjpg, action=streamLive camera stream (MJPEG)
….jpg, ….png, snapshot, image.cgiStill image, refreshed (default every 2 s)
….mp4, ….webmVideo (muted, looping)
….m3u8HLS live stream
YouTube linksYouTube player (muted autoplay)
Anything elseWeb page in a sandboxed frame

Set data-mode (mjpeg, snapshot, video, hls, page, html) to override the guess, data-fit="cover" to fill the box, and --sge-height or a height to size it (16:9 by default).

Things to know

Use https addresses. Browsers block http:// video and pages inside a secure site. Many on-site cameras are http://192.168…; use the camera's https address or the vendor's cloud viewer.

RTSP doesn't play in browsers. If a camera only offers rtsp://, use an NVR or cloud service that provides HLS or a web viewer.

Some sites block embedding. If a web page stays blank, that site doesn't allow being shown inside another page. Look for its "embed" or "share" link.

Sandboxed. Web pages and custom HTML can show content and run their own scripts, but can't read this site's saved data (like a futures API key), change the page, open pop-ups or redirect the screen. Use a view-only camera login.
